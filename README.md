# 地球Online（牛马版）· 游戏化职场成长工作台

把上班生涯当作一场人生游戏来经营：记录每一段真实经历，点亮你的职场技能树，攒经验、升级、保存你的成长存档。

> 灵感与视觉风格来自「地球Online 大学版」（作者 @塑料叉），本仓库为其职场向改造版本。

## ✨ 功能模块

| 模块 | 说明 |
|------|------|
| 🚀 启动流程 | 启动页 → 玩家档案（公司/职位/工龄）→ 角色形象选择（预设背景 × 角色 Canvas 合成）→ 首页 |
| 🏠 人物面板 | 人物卡 · LV.1-30 经验条 · 22 类职场技能等级 · 本月日历 · 今日清单（昨日未完成自动顺延）· 最近经历 · 正在学习 · 每日答案之书 · 底部导航 |
| 📖 经历库 | 四段式记录（发生了什么 / 我做了什么 / 结果 / 我的感受），本地规则引擎自动识别 21 类职场技能并给出点亮建议 |
| 🌳 技能树 | 已拥有 / 学习中 / 想学；领域知识库（Excel · AI 提效 · 项目管理 · 职场沟通等）自动拆解学习计划与每日任务；🏆 验证任务通过真实经历点亮 |
| 💾 存档 | 像素风人物存档卡（纯 Canvas 绘制长图），多版本历史，可回看保存 |

## 🛠 技术特点

- **零外部依赖**：单页 HTML + 原生 JS/CSS，无任何 CDN / 框架 / 图表库
- **纯 Canvas**：存档长图、角色形象合成、像素风 UI 全部手绘实现
- **离线优先**：localStorage 持久化，数据不丢
- **在线同步（可选）**：按 `database-sdk-contract` 对接 WorkBuddy 资料库数据表（`window.__SMART_PAGE__.database`），支持云端读写与双向同步，离线自动降级本地缓存
- **移动端适配**：mobile-first 单栏布局，按钮 ≥44px，适配底部安全区

## 🚀 快速开始

```bash
# 方式一：直接打开
# 双击 index.html 或用任意静态服务器
python -m http.server 8080
# 浏览器访问 http://127.0.0.1:8080

# 方式二：部署到 WorkBuddy 资料库（获得在线链接 + 云端数据表同步）
# 将 src/ 打包为 zip 后通过资料库「导入 HTML」能力上传，并绑定 4 张数据表
# （eo_玩家档案 / eo_经历库 / eo_技能 / eo_任务，字段见 data-*.json）
```

## 📂 目录结构

```
src/                页面源码（index.html + assets/{css,js,img}）
data-*.json         演示数据种子（4 张数据表示例记录）
tools/              构建/测试脚本（冒烟测试、E2E、图片优化、SDK lint 合并器）
reference-*.html    原版参考页
```
